Two independent methods propose where a dual epitope tag (ALFA + SpyTag/DogTag) can be inserted so it displays on the cell surface. The deterministic pipeline computes sites from AlphaFold structure + topology + ortholog conservation; the literature agent retrieves validated tagging precedents from the web. Below: how each did against known-good controls, where they disagree, and what to trust.

Where each method wins

Deterministic catches what has no paper

Wins on TFRC, AXL, TMEM123, ITGB5 — ordered surface loops (Path 2b) and disordered ectodomain stretches (Path 2a) that no one has published a tag for. TFRC I290/V291 is the flagship: a confidently-folded loop (pLDDT 96) the old low-pLDDT screen structurally misses, recovered because pLDDT here is a reliability gate, not a disorder gate. Insertion is snapped to the exposed junction residue (V291, RSA 0.88).

Literature catches what structure can't see

Wins on ITGB1, TRPC5, hERG — the multi-pass channel loops where AlphaFold is unreliable (hERG S1–S2 scored as helix at pLDDT 50) or the loop is real but too tight for the RSA gate (TRPC5 Y460 at 0.22). A published, validated tag beats a structural guess every time — when one exists.

tag_fit — the chemistry recommendation is sound

Each site carries a computed tag recommendation from loop geometry: ALFA (α-helix, folds alone → any exposed loop), SpyTag003 (β-strand → needs an extended ≥10-aa loop), DogTag (loop-adapted → short loops SpyTag can't do).

Trust & honesty gates

position_evidence: validated vs inferred

Every literature site records whether the exact residue was stated in a paper (validated) or inferred from a domain-level claim (inferred), plus the cited_tag_residue it read. This exposes "domain → position" laundering — e.g. AXL M25 and ITGB5 D388/E425 are flagged inferred, not sold as facts. Caveat still open: the label swings run-to-run (one TFRC batch over-claimed everything "validated"). Needs an adversarial citation-check pass before scaling.

New: topology / signal-peptide normalization gate

Just added (normalize.py, 4/4 tests). Rejects any proposed site not actually displayed extracellularly: internal or C-terminal sites in a non-O compartment, an N-terminal tag on a type-II intracellular N-terminus (the TFRC trap), and — critically — a terminal tag that falls inside the signal peptide and would be cleaved off. This is the same signal-peptide-cleavage rule the Willow method enforces (below).

Related method — Willow (key item to check)

Willow (bioRxiv 2025.09.19.677468) N-terminally HA-tags GPCRs. For signal-peptide receptors it runs SignalP 6.0 (cleavage) + NetSurfP-2.0 (disorder), inserts HA between the predicted cleavage site and the structured N-terminus, then re-predicts cleavage + disorder for each design and keeps the one that preserves cleavage without adding disorder.

  • Same as us: disorder/structure-driven placement + signal-peptide-cleavage awareness (our new SP gate).
  • Gap 1 — terminal design. Willow designs N-terminal tags; we only produce internal loops and reject bad terminals. → add SP-cleavage-aware N-terminal design.
  • Gap 2 — insertion re-verification. Willow re-runs its predictors on each candidate; we don't yet check whether inserting the cassette shifts cleavage or adds local disorder. → add an insertion-effect loop.

Recorded in the design spec §14 as a key item to check.
